# FPS Game Planning Example

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **Maze Escape** |
| 장르 | FPS / Action / Survival |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개
> 다가오는 괴물들을 처치해 열쇠를 얻고 미로처럼 생긴 동굴을 탈출하라

---

## 2. 게임 컨셉

플레이어는 보물을 찾기위해 미지의 동굴을 탐험하던 도중 갑자기 동굴이 움직이면서 미로처럼 바뀌어 플레이어는 동굴에 갇히게 된다

미로에선 숨어있었던 괴물들이 깨어나고 플레이어는 다가오는 괴물들을 처치하고 열쇠를 얻어 미로를 탈출하는 것이 최종목표이다.

### 핵심 키워드

- **Explore** : 미로탐색
- **Combat** : 적과의 전투 
- **Collect** : 동굴 탐색 및 무기 보급, 열쇠 획득
- **Escape** : 동굴 입구 개방 및 동굴 탈출

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 동굴을 탐색하면서 보급을 획득
2. 등장하는 괴물 처치
3. 괴물처치 및 열쇠획득
4. 동굴의 입구 도착
5. 열쇠로 잠겨있는 동굴 입구 개방
6. 제한 시간 안에 탈출하면 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
적 발견
  ↓
조준 및 사격
  ↓
적 처치
  ↓
아이템 / 탄약 획득
  ↓
다음 구역 이동
  ↓
열쇠 획득
  ↓
탈출
```

플레이어는 게임이 종료될 때까지 **탐색 → 전투 → 아이템 획득 → 이동**의 과정을 반복한다.

---

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Left Click | 총 발사 |
| Right Click | 조준 |
| Space | 점프 |
| Shift | 달리기 |
| R | 재장전 |
| E | 아이템 획득 / 문 상호작용 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 FPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기
